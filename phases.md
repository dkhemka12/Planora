# Planora — Development Phases

## Phase 1 — Project Setup
- Create Git repository.
- Create client and server folders.
- Configure React.
- Configure Express.
- Configure environment variables.
- Add .gitignore.
- Create initial README.
- Create basic folder structure.

## Phase 2 — Database Setup
### PostgreSQL
- Create users table.
- Create subjects table.
- Add primary and foreign keys.
- Test a JOIN query.

### MongoDB
- Connect MongoDB.
- Create Task schema.
- Create StudyPlan schema.
- Test CRUD operations.

## Phase 3 — Backend Foundation
- Configure Express.
- Add JSON middleware.
- Create route structure.
- Create controllers.
- Create authentication middleware.
- Create error middleware.
- Implement proper HTTP status codes.

## Phase 4 — Authentication
- Register API.
- Login API.
- Password hashing.
- JWT generation.
- Auth middleware.
- Protected routes.

## Phase 5 — Subject Management
- Subject CRUD APIs.
- Connect subjects to users.
- Build subject UI.
- Add client-side routing.

## Phase 6 — Task Management
- Task CRUD APIs.
- Task form.
- Task list.
- Task card.
- Complete/uncomplete task.
- Filtering.
- Loading/error states.

## Phase 7 — Dashboard
- Fetch task and subject data.
- Calculate progress.
- Show statistics.
- Show recent tasks.
- Add navigation.

## Phase 8 — AI Integration
- Connect backend to LLM API.
- Store API key in environment variables.
- Write study-plan prompt.
- Implement structured output.
- Add AI study-plan endpoint.
- Add AI explanation endpoint.
- Handle LLM errors.

## Phase 9 — AI Frontend
- Build planner form.
- Fetch AI plan asynchronously.
- Display plan by day.
- Add save-plan functionality.
- Build concept explainer.

## Phase 10 — Saved Plans
- Implement saved-plan API.
- Display saved plans.
- Delete saved plans.

## Phase 11 — JavaScript Demonstrations
Ensure the project/code clearly demonstrates:
- async/await
- Promises
- callbacks
- closures
- event loop
- hoisting

These should be documented in the project rather than artificially forcing unnecessary features.

## Phase 12 — Testing & Cleanup
- Test all endpoints.
- Test frontend flows.
- Test validation.
- Test error handling.
- Test authentication.
- Test AI failure cases.
- Remove unnecessary code.
- Improve README.

## Phase 13 — Final Git Workflow
- Use feature branches.
- Make focused commits.
- Merge tested features into main.
- Tag final MVP release.
